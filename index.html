NailDesk

Booking and deposit platform for independent nail technicians. Clients book over WhatsApp, pay a deposit, and the tech gets paid out without chasing anyone.

React · Spring Boot · Supabase · Paystack · WhatsApp Cloud API · Cloudflare Workers

  • WhatsApp booking flow with deposit links and reminders
  • Per-tech Paystack subaccounts, with true net earnings after fees
  • Bank details verified through Paystack and encrypted with AES-256-GCM
  • Public portfolio pages with custom booking links and search previews
Built · pre-launch

Handshake

Peer-to-peer marketplace with escrow. Buyer funds are held until both sides confirm the meetup with a one-time code.

Spring Boot · React · Postgres · Redis · PayFast · Brevo

  • Escrow lifecycle with OTP meetup verification
  • JWT auth, optional two-factor login and Redis-backed rate limiting
  • Real-time chat with read receipts
  • Meetup map ranking safe spots by road distance and travel time
